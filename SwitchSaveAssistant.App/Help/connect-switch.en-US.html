How to connect the Nintendo Switch

Connection used by Switch Save Assistant: USB-C + DBI + MTP.

Important: keep the Nintendo Switch offline. Switch Save Assistant does not require internet access on the console.
1

Start the Switch with Atmosphère

Enter the environment where you normally use Atmosphère and hbmenu.

2

Open DBI

Run DBI from hbmenu.

3

Connect the USB-C cable

Connect the Switch directly to the computer with a cable that supports data transfer.

4

Enable the MTP responder

In DBI's main menu select Run MTP responder.

The X button in DBI's main menu also starts this mode.

5

Check Windows

Open File Explorer. Under This PC, a device named Switch should appear.

DBI should expose 1: SD Card and 7: Saves.

6

Return to Switch Save Assistant

On Folder ⇄ Switch, click Detect.

Expected result

Switch Save Assistant should show:

● Connected: Switch

Switch not detected?

  • Make sure DBI is still in Run MTP responder.
  • Disconnect and reconnect the USB-C cable.
  • Try another USB port.
  • Confirm the cable supports data, not only charging.
  • Check that the Switch device appears in File Explorer.
  • If needed, exit the MTP responder and enter it again.
