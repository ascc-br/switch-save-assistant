Como conectar o Nintendo Switch

Conexão usada pelo Switch Save Assistant: USB-C + DBI + MTP.

Importante: mantenha o Nintendo Switch offline. O Switch Save Assistant não precisa de internet no console.
1

Inicie o Switch com Atmosphère

Entre normalmente no ambiente em que você utiliza Atmosphère e hbmenu.

2

Abra o DBI

Execute o DBI através do hbmenu.

3

Conecte o cabo USB-C

Conecte o Switch diretamente ao computador usando um cabo que suporte transferência de dados.

4

Ative o MTP responder

No menu principal do DBI, selecione: Run MTP responder.

No menu principal do DBI, o botão X também inicia esse modo.

5

Confira no Windows

Abra o Explorador de Arquivos. Em Este Computador, deverá aparecer um dispositivo chamado Switch.

Entre as áreas disponibilizadas pelo DBI, deverão existir: 1: SD Card e 7: Saves.

6

Volte ao Switch Save Assistant

Na tela Folder ⇄ Switch, clique em Detectar.

Resultado esperado

O Switch Save Assistant deverá mostrar:

● Conectado: Switch

Switch não detectado?

  • Confira se o DBI ainda está em Run MTP responder.
  • Desconecte e reconecte o cabo USB-C.
  • Experimente outra porta USB.
  • Confirme que o cabo suporta dados, não apenas carregamento.
  • Verifique se o dispositivo Switch aparece no Explorador de Arquivos.
  • Se necessário, saia do MTP responder e entre novamente.
